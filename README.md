# CloudWorld Forum

Полноценный форум Minecraft-проекта **CloudWorld** на Next.js и PostgreSQL.
Данные, роли, права, темы, сообщения и настройки общие для всех устройств.

## Первый владелец

В существующей базе аккаунт владельца и его пароль не меняются. Для новой пустой
базы его можно однократно создать через серверные переменные
`FORUM_OWNER_USERNAME` и `FORUM_OWNER_PASSWORD`; пароль не хранится в репозитории.
После первого входа его нужно сменить в разделе «Профиль → Безопасность».

## Возможности

- регистрация, вход, защищённые серверные сессии, CSRF и bcrypt;
- разделы, подразделы, темы, ответы, черновики и история правок;
- динамические статусы, теги, реакции, закладки и подписки;
- назначение ответственных и передача обращений между отделами;
- шаблоны ответов с переменными и автоматическими действиями;
- личные сообщения, уведомления, подписчики и блокировки;
- модераторский центр: очередь, санкции, аудит и корзина;
- редактор ролей, детальных прав, структуры и форм создания тем;
- интеграции через HTTPS webhook без хранения секретов в базе;
- безопасные добавочные миграции существующей базы данных.

## Стек

- Next.js 16 + TypeScript + Tailwind CSS;
- PostgreSQL (Neon через Vercel Marketplace);
- `pg` и `bcryptjs`;
- Node.js 20.19+.

## Локальный запуск

Создайте `.env.local` на основе `.env.example`, затем выполните:

```bash
npm install
npm run dev
```

Сайт откроется по адресу http://127.0.0.1:3847.

Проверки перед публикацией:

```bash
npm run lint
npm test
npm run build
```

## Vercel

Репозиторий: https://github.com/ivanzolow833-droid/nit-forums

- Framework Preset: `Next.js`;
- Install Command: `npm install`;
- Build Command: `npm run build`;
- Output Directory: стандартный Next.js;
- Root Directory: `./`.

Neon должен быть подключён к проекту с переменной `DATABASE_URL` для Production
и Preview. `AUDIT_IP_SALT` задаётся отдельной длинной случайной строкой. После
изменения переменных выполните повторный деплой.

## Роли и права

В поставку входят роли игрока, помощников, модераторов, медиа-состава,
разработчиков, администраторов, технического состава, владельца и `MrProper`.
Названия, приоритет, оформление и каждое разрешение редактируются владельцем в
панели управления. Системные роли владельца защищены от удаления.
